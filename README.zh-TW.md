# Promptary

[English](./README.md) | [正體中文](./README.zh-TW.md)

*你的咒語收藏庫 —☆ﾟ.*･\*

Promptary 是一個收藏 AI 生圖咒語（prompt）與實測紀錄的小工具。

常常在網路上看到好看的 prompt，卻沒有一個方便保存和整理的地方，所以趁 Codex 重置前燒 token 做了 Promptary，把參考圖片、原始咒語、來源，以及自己的生成結果和心得都放在一起。

🔗 [線上使用 Promptary](https://phcy0614.github.io/promptary/)

不需要登入，收藏與圖片保存在自己的瀏覽器裡。支援正體中文與英文介面，目前沒有雲端或跨裝置自動同步。

## 使用流程

1. 新增收藏，加入參考圖片、咒語、來源與筆記；也可以先存圖片，之後補文字。
2. 透過搜尋、標籤、狀態與最愛找回收藏。
3. 複製咒語到生圖平台使用。
4. 在收藏內新增嘗試，記錄成果圖片、實際使用的咒語、平台、模型、評分與筆記。
5. 選取兩張圖片並排比較，查看各自對應的咒語與紀錄。

## 目前功能

- **收藏整理**：收藏與嘗試皆可命名，支援標籤、搜尋、狀態篩選、排序與最愛。
- **嘗試紀錄**：每筆收藏可記錄多次嘗試，保存成果圖片、平台、模型、日期、評分與筆記，也能管理自訂平台。
- **咒語閱讀**：切換原文與分類閱讀，並手動調整分類。分類依本機中英文關鍵字判斷，不會修改原文或複製內容，也不會呼叫 AI 服務。
- **圖片比較**：參考圖與成果圖皆可設為封面；支援任選兩張圖片比較，手機也能雙圖並排，並切換查看兩側資訊。
- **表單保護**：有未儲存變更時，關閉表單會先確認；儲存失敗時保留輸入，方便重試。
- **雙語介面**：支援正體中文與英文切換，語言偏好保存在目前瀏覽器。

## 圖片處理

參考圖片與成果圖片使用相同規則：

- 支援 JPEG、PNG、WebP。
- 單張檔案上限為 10 MiB，解碼後最多 4,000 萬像素。
- 單次最多選取 10 張；超過時整批拒絕，可以改成分批加入。
- 每個表單最多同時處理 2 張，後續批次會排隊處理。
- 不限制每筆收藏或嘗試的圖片總張數，但仍受瀏覽器儲存容量限制。

圖片會在本機縮放與重新編碼，保存版本的長邊最多為 2048 像素。優先使用 WebP，瀏覽器不支援時改用 JPEG 或 PNG。

**Promptary 保存的是處理後的圖片，不是原始檔案封存工具；需要保留原尺寸或原始品質時，請另存原檔。**

## 資料保存與備份

收藏與圖片保存在目前瀏覽器的 IndexedDB。不同裝置、瀏覽器或網站網址各自保存資料；正式網站與本機開發網址也不共用圖庫。

清除網站資料可能刪除收藏，無痕模式也不適合長期保存。請定期透過「管理 → 匯出」下載 ZIP 備份。

ZIP 包含收藏、嘗試紀錄、處理後圖片與自訂平台清單。匯入方式：

1. 開啟「管理 → 匯入」，選擇 Promptary 匯出的 ZIP。
2. 查看預計新增、更新與保留的數量。
3. 確認後才寫入本機圖庫。

相同收藏 ID 會比較更新時間：備份較新就更新整筆收藏；本機較新或時間相同則保留本機版本。這不是逐欄位合併，自訂平台清單則會合併並去除重複項目。

目前 ZIP 匯入上限為 **100 MiB**，宣告解壓總量上限為 **200 MiB**。舊版 JSON 備份不支援直接透過目前的匯入介面還原。

「管理 → 本機資料」可查看瀏覽器回報的儲存用量與資料保護狀態。資料保護仍由瀏覽器決定，不能取代 ZIP 備份，也不代表自動同步。

## 本機開發

使用 React 19、TypeScript、Vite 8、Tailwind CSS v4 與 IndexedDB。

介面以 Figma Make 產出的設計為基礎，開發與除錯過程使用 OpenAI Codex 協助。

專案工具設定為 Node.js 22 與 pnpm 10.34.3。

```
pnpm install
pnpm dev
```

依終端機顯示的本機網址開啟預覽。

檢查與建置：

```
pnpm typecheck
pnpm test
pnpm build
```

架構概要與日期式開發紀錄請見 [開發說明](./doc/DEVELOPMENT.zh-TW.md)。
